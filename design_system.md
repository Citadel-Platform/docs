# Citadel Platform Design System

## Basic Idea

- it will look like the Google Cloud platform UI, with tables, straightforward components such as forms, menus, dropdowns, cards, etc. Nothing sleek or modern or playful
- it will not have very rounded corners


## Colour Tokens

Grey: 797D82
Background blue: 0B121C
Accent: 3C6E71

The gray's opacity is played around with to acheive the different shades used in the reference

## Font

Font is Cairo, the font files are already added under citadel_platform/assets/fonts/Cairo, but you need to register the fonts in the pubspec file
